## 已决策项

### 产品层
- **注册方式：** 邮箱 + 手机号
- **推送频率：** 用户可自调，分"新片上线（类型匹配）"和"定时推送"两种
- **推送渠道：** 初期邮件，后期扩展短信
- **反馈机制：** 暂不做
- **管理后台：** 暂不需要
- **平台：** 仅 Web 端，暂无移动端

### 数据层
- **数据来源：** TMDB API（主数据源，全量电影元数据）+ 豆瓣（评分/评论，按需爬取）
- **评价体系：** 豆瓣评分 + AI 分类标注

### 网站功能
- **欢迎/注册/登录页：** 注册时可选电影类型偏好（可跳过）
- **首页：** 系统推荐给该用户的电影列表（分页展示）
- **电影浏览页：** 搜索 + 按类型/年代/地区筛选
- **电影详情页：** 展示海报、简介、评分、演员等信息（暂不展示观看渠道）
- **我的推荐页：** 所有历史推荐记录
- **设置页：** 类型偏好 + 推送频率 + 邮件开关
- **推荐卡在首页展示：** 每部推荐电影包含海报、标题、豆瓣评分、推荐理由
- **未设置偏好：** 推荐位置引导用户选择类型
